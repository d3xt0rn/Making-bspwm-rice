# Building My BSPWM Rice from Scratch

> A personal log of building a clean and lightweight Linux desktop from zero.

## Goal

This project documents how I build my own **bspwm** desktop environment from scratch. The goal is to create a minimal, fast, and good-looking setup while understanding every component instead of using a pre-made configuration.

This repository is both a backup of my configuration and a guide for anyone interested in creating a similar setup.

---

## Philosophy

* Minimal software
* Fast startup
* Easy to customize
* Keyboard-driven workflow
* Every component has a purpose

No desktop environment.
No unnecessary background services.
Only the tools I actually use.

# Why bspwm?

I wanted a window manager that is:

* lightweight
* simple
* highly configurable
* based on binary space partitioning
* easy to script

bspwm provides exactly that while staying minimal.
